逐项修复

01 Apple 图片字节通道
FlutterCompressPlugin 在桥接层把 Data 包装成 FlutterStandardTypedData；图片引擎继续独立于 Flutter。

02 并发任务状态
公共视频调用按进入顺序排队，排队 token 可取消；后端入口增加占用保护。
CancellationToken 不能在有未完成任务时 reset，避免丢失取消绑定。

03 保存源文件自身
相同文件身份直接返回已有路径；先复制到临时文件再移动，已有目的文件采用新名字保留，不先删除。
Android 旧版 Downloads 分支同样保留现有文件。

04 输出路径与覆盖
桌面采用独占文件创建，碰撞时递增后缀；Android/Apple 使用独立任务子目录。
符号链接、../、已有 -1 文件均不会使输出覆盖源文件。

05 Apple 缩放
视频 composition 明确组合源旋转、原点平移和目标缩放。
真实原生回归已检查横屏与旋转源的四角颜色，输出尺寸正确且画面未被裁掉。

06 Apple 失败/回退
增加 HEVC 失败后的 H.264 重试、append 返回值检查与状态监测。
视频/音频泵使用幂等完成句柄，取消和写入失败都能完成 Future，并清理输出及编解码状态。
后台执行额度移入独立辅助类；管线构造和估算已拆分，保持原生 lint 通过。

07 Web 取消
Dart 跟踪脚本加载、元数据读取和编码阶段的取消状态。
元数据 fetch 与视频 fetch 绑定 AbortController；取消不再在编码开始时被抹掉。
脚本加载、元数据解析和缩略图等待有超时，防止永久等待。

08 Web 失败清理
整个编码生命周期受最外层 finally 保护，包含 fetch、配置和解码器创建前后的失败。
编码器、解码器、活动 id 和取消状态均有对应清理；失败后可重试。

09 Web 时长/帧率
结果由实际编码帧时间戳跨度计算，不再用请求 fps 除帧数。
真实浏览器输入 4 秒/24fps，输出探测与报告均为 4 秒，报告帧率约 24fps。

10 Web 内存与背压
元数据读取的源 buffer 可由紧接的编码复用；保留缓存数量有界并设过期时间。
解复用每批 8 个样本，限制解码/编码队列，消费后释放样本数据。
不会在每批之间 flush 解码器，避免 WebCodecs 刷新后的关键帧要求破坏后续解码。

11 桌面图片目标体积
JPEG、PNG、WebP 共用目标搜索和尺寸降级；保存最佳候选，不再用最后一轮覆盖结果。
先解码/限制源尺寸，再做质量搜索；目标不可满足时明确报错，临时目录在 finally 清理。
真实 FFmpeg 测试覆盖文件与内存两条入口，三种格式均达到 5KB 上限。

12 真实元信息
桌面编码后重新探测输出，帧率上限不再提升低帧率源；hasAudio 取真实音轨。
Android/Apple skipped 返回源文件时，时长、编码、帧率、音轨也使用源元信息。
裁剪结束超过全长时按有效全长处理。

13 Release 校验
Dart 与原生入口增加运行时配置验证，覆盖正数范围、有限帧率、裁剪与百分比。
非法裁剪起点在媒体范围外会报错；Apple 还拒绝非有限/无效媒体尺寸与时长。

14 极小尺寸与 none
三端数学实现不再把极小源扩大到 16 像素；none 保留精确整数尺寸。
不支持奇数或极小尺寸的具体编码器仍可返回明确编码错误，不静默放大源画面。

15 缓存维护
公共入口及两端原生桥接拒绝在操作尚未完成时清缓存，并保护独占输出。
Apple 缓存遍历/删除移至工作队列，避免主线程大文件 IO。

16 Android 主线程工作
视频探测和输出目录准备移至 IO 调度器，仅保留 Transformer 所需的 Looper 交互。

17 Android 图片最终结果
检查 Bitmap.compress 成功标志和非空输出；附加 EXIF 后重新检查最终大小与保留原图阈值。
不能在目标内保留元数据时明确报错，并删除不完整输出。

18 示例生命周期
公共 DemoSession 统一挂载状态、有限长度日志、输出所有权与保存/释放。
文件选择、探测和估算增加请求版本检查，旧请求不能覆盖新输入；视频页面销毁会取消 token。
Web 下载 helper 给浏览器消费 URL 的时间，示例在保存后释放自产 Blob。

19 FFmpeg 下载
固定 autobuild-2026-10-16-13-04 / N-127579-g5cb9fcd211，四种平台归档摘要固定。
SHA-256 校验归档，安装清单校验缓存二进制；ABI 隔离缓存，跨进程锁保护安装。
下载和解包进入临时目录，完成后移动安装目录；失败清理临时文件。
Windows 的 tar 缺失也能进入 PowerShell 回退，路径通过环境变量传递而非拼进命令。
能力检测不触发下载；环境变量覆盖可分别指定 FFmpeg/FFprobe。
